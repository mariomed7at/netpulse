# Changelog

All notable changes to NetPulse are documented here.

## [0.1.0] - Unreleased

### Added
- Initial ICMP ping wrapper with structured result metrics.
- TCP port connectivity checks using the Python standard library.
- Native traceroute/tracert wrapper and basic hop parsing.
- JSON-capable command-line interface.
- Unit tests, contributor guidance, security policy, and CI workflow.
