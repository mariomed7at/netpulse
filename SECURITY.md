# Security Policy

## Supported versions

Security fixes are currently considered for the latest released version of NetPulse (`0.1.x`). This is an early alpha project and does not yet provide a formal service-level commitment.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature (private vulnerability reporting) on the repository when enabled. Include the affected version, impact, and a minimal reproducible description. Avoid sending real credentials or customer data.

NetPulse is a diagnostics tool and should only be used against systems and networks you own or are explicitly authorized to test.
